    Le client guide, le serveur décide

    session.js redirige pour le confort de l'utilisateur. La vraie protection est côté API : jeton (401), rôle admin relu en base (403), propriété de chaque tâche (404).

    Chaque couche ne parle qu'à sa voisine

    Le contrôleur ne connaît que son service, le service que son repository. Le SQL reste dans les repositories ; les modèles n'importent rien.

    Une base dans le processus

    SQLite tourne dans Node via node:sqlite, sans serveur à installer. Les tests repartent d'une base :memory: vierge à chaque fichier.
